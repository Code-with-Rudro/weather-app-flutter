# 🌦️ Flutter Weather App

A simple and modern **Weather Application built using Flutter** that displays real-time weather information using a **Weather API**. 
The app fetches weather data from an external API and displays temperature, weather conditions, and other details in a clean and user-friendly interface.

---

## 🎓 College Project

This project was developed as part of our **college-based learning project** to understand **Flutter application development, API integration, and real-time data handling**.

The goal of this project is to gain practical experience in:

- Mobile App Development using Flutter
- API Integration
- UI Design
- Real-time Weather Data Fetching

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/weather-app-flutter.git
```

---

### 2️⃣ Navigate to Project Directory

```bash
cd weather-app-flutter
```

---

### 3️⃣ Install Dependencies

```bash
flutter pub get
```

---

### 4️⃣ Run the Application

```bash
flutter run
```

---

## 🔑 Weather API Setup

1. Create an account on a weather API provider (Example: OpenWeather).
2. Generate your **API Key**.
3. Replace the API key in your weather service file.

Example:

```dart
const apiKey = "YOUR_API_KEY";
```

## 📌 How the App Works

1. User opens the app.
2. The app sends a request to the Weather API.
3. The API returns weather information in JSON format.
4. Flutter processes the data.
5. Weather information is displayed on the screen.
